# Pin Configuration

| Component    | Pin | Connected To |
| ------------ | --- | ------------ |
| MAX30102     | SDA | GPIO 8       |
| MAX30102     | SCL | GPIO 9       |
| OLED Display | SDA | GPIO 8       |
| OLED Display | SCL | GPIO 9       |
| LM35         | OUT | A0           |
| LM35         | VCC | 3.3V         |
| LM35         | GND | GND          |

> Note: The IndusBoard Coin V2 uses the onboard I²C interface for the MAX30102 and OLED display.
